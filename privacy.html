Política de Privacidad

Última actualización: 16/11/2026

Este bot multifunción de Discord utiliza información proporcionada por Discord únicamente para ejecutar sus comandos y funciones.

Información utilizada

  • Identificadores de usuarios.
  • Nombres de usuario.
  • Identificadores de servidores y canales.
  • Roles y permisos.
  • Mensajes cuando son necesarios para ejecutar comandos.

Uso de la información

La información se procesa únicamente para ejecutar comandos, administrar servidores y proporcionar las funciones del bot.

Almacenamiento

El bot no utiliza una base de datos para almacenar permanentemente información personal de los usuarios. Los datos necesarios se procesan durante la ejecución de las funciones.

Compartición

No vendemos información personal ni la compartimos con fines publicitarios.

Contacto

Para consultas sobre privacidad, contacta con el soporte oficial del bot.
